# Submission checklist

Taken from the Participant Guidebook. Submit on Hack2Skill: https://hack2skill.com/event/datathon-2026

## Required

- [ ] Project title in the form `marvel_IBM Z Datathon 2026 Project`
- [ ] Demo video, **3 minutes max**, covering:
  - [ ] the problem statement
  - [ ] data that supports the problem
  - [ ] our solution, with a live demo
  - [ ] how it uses IBM Z: tech stack, our LinuxONE instance and the model running on it
- [ ] Link to this GitHub repo (it must be public)
- [ ] Links to every open-source library, framework and dataset used (listed in the README)

## Before building (mandatory)

- [ ] Lab 1: Predictive AI, hybrid AI scenarios (multi-model)
- [ ] Lab 2: Predictive AI + Generative AI

## Optional (recommended)

- [ ] Architecture flowchart (`docs/architecture/`)
- [ ] Working prototype

## Evidence for the "Technical Design" score

Screenshots in `docs/screenshots/` of platform capabilities we use:

- [ ] model training / inference running on LinuxONE
- [ ] containerisation
- [ ] security
- [ ] scalability / compute resources

## Originality rules to keep in mind

- All code is written during the event window (Oct 17–18, 2026). Commit early and often so the history shows it.
- No reuse of prior personal projects or other teams' code.
